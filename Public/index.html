Diet Manager Guide

Welcome to Tubby

Tubby helps your family record meals, nutrition, fruit and vegetable intake, and weight progress. Follow the steps below to set up your family.

1. Set up a family for the first time

  1. Choose Sign Up on the login screen.
  2. Enter a new Family ID. Use a simple name such as SMITH_FAMILY; remember it exactly, because other adults joining your family will need the same ID. IDs are converted to uppercase.
  3. Enter your name, email address and a password, then create the account.
  4. If this Family ID does not already exist, Tubby creates the family and makes this first login account the Family Admin. A starter profile is created for the admin too.
  5. After signing in, open Admin Settings to configure the AI food scanner (see step 4), then use the Family area to add profiles for the people you want to track.

If the Family ID already exists, a new login account is created as a pending request. The Family Admin must approve it before it can be used to access the family.

2. Login accounts and family member profiles are different

Login account

A login account uses an email address and password. It lets someone sign in to Tubby. The first account for a new family becomes its admin; additional accounts using the same Family ID need admin approval.

Family member profile

A profile represents a person whose meals, nutrition or weight may be tracked. Add profiles from the Family area. A profile does not automatically create a login account, and children or other family members who do not need to sign in can have a profile only.

For example, one parent can have a login account and create profiles for both parents and their children. Create separate login accounts only for people who need to access Tubby themselves.

3. Add people and manage access

  • Open the Family tab and choose + Add Person to create a member profile. Set the person's role, goals and tracking preferences.
  • The Family Admin can manage family profiles and approve pending login requests in Admin Settings.
  • To give another adult their own login, ask them to choose Sign Up and enter your existing Family ID. The admin must approve their request.
  • Keep your Family ID available for trusted household members who need their own login. Do not share account passwords.

4. Set up Google Gemini for AI food scanning

The photo scanner uses Google's Gemini AI to estimate food or product details from a meal photo or nutrition label. A Google account and a Gemini API key are needed to use this feature. You can still enter food details manually without scanning.

  1. Sign in to a Google account and open Google AI Studio – API keys.
  2. Follow Google's prompts to create or select a project and create an API key. Keep the key private; do not post it publicly or send it to anyone you do not trust.
  3. Sign in to Tubby as the Family Admin and open Admin Settings using the shield icon near the top of the app.
  4. Paste the key into the Google Gemini API Key field, choose Test Key to check it, then save it.
  5. Try taking a food photo or uploading a nutrition label. Review the suggested values before saving your food entry.

Important about the API key

In the current version, Tubby saves the key in this browser on this device; it is not automatically shared across the family’s other devices. If another device needs AI scanning, configure a key there too. Google may apply usage limits or charges depending on its current terms and account setup, so check the details in Google AI Studio. Treat the key like a password.

5. Using Tubby

  • Use the profile selector near the top to choose the person you are logging for.
  • On Today, scan a meal or enter the details manually and check the estimated nutrition values.
  • Use Fruit/Veg to review weekly servings and Weight to record weight progress.
  • Use the Family tab to switch between profiles and manage people you track.

Having trouble?

Check that your email and password are correct. If a new login was created for an existing family, ask the Family Admin to approve it. If AI scanning fails, check the API key in Admin Settings and test it again. You can still add entries manually if the scanner is unavailable.
